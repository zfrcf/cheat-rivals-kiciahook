# Leçons — règles explicites (priorité haute)

Règles tirées des commentaires de l'utilisateur. Elles priment sur les statistiques.
Une règle continue fixe un plancher (`+`) ou un plafond (`-`) via `cible` ; `=v` impose
une valeur, `!v` l'évite. Une nouvelle règle sur le même paramètre et le même profil
archive l'ancienne (jamais de suppression silencieuse).

Format : `- [date] profil=<profil|*> param=<nom> direction=<+|-|=v|!v> cible=<valeur> | « commentaire »`
